# missions

課題パック。1パック1ディレクトリで、説明・初期データ・注入レシピ・対策候補・テスト・ヒント・解説を持つ（spec §11）。

| パック | 種類 | 題材 |
| - | - | - |
| `onboarding/` | 練習（`tutorial`） | メモのタイトルの文字数制限が、保存する処理で確かめられていない。操作ガイドに沿って、こわす（再現）→ なおす（対策）→ たしかめる（検証）→ ふりかえる を 3 分で一周する |
| `idor/` | 課題（`mission`） | メモを ID 指定で取り出す処理が所有者を照合しない（IDOR、spec §8.1）。画面のリンクだけを隠す・すべて断る・所有者を照合するの 3 つの対策を試す |
| `sqli/` | 課題（`mission`） | 検索語を SQL へ文字としてつなぐ（SQL インジェクション、spec §8.3）。語の禁止・検索の停止・値としてのバインドの 3 つの対策を試す。実行するのは SQLite |
