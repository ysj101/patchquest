# PatchQuest（ローカル版）

学習用に脆弱性を注入した架空のサービスで、アプリの事故を調べて、直して、確かめる練習をする教材です。演習はすべてこのパソコンのブラウザの中で動き、インターネットには接続しません。

## 必要なもの

- PC版の Google Chrome（動作を確認した版：Chrome 154）。Edge など他のブラウザは対象外です
- 静的なファイルを配信する仕組み。以下では Python 3 を使います（`python3 --version` で確認できます）

## 起動のしかた

1. この ZIP を展開します。
2. 展開してできたフォルダ（`index.html` が入っているフォルダ）でターミナルを開きます。
3. 次のコマンドを実行します。
   - macOS・Linux：`python3 -m http.server 8000 --bind 127.0.0.1`
   - Windows：`py -m http.server 8000 --bind 127.0.0.1`
4. ブラウザで <http://127.0.0.1:8000/> を開きます。

`index.html` をダブルクリックして開く方法（`file://`）では動きません。必ず上の手順で開いてください。

終わるときは、ターミナルで Ctrl + C を押します。

## うまく動かないとき

- 「アドレスは既に使用されています」と表示される：`8000` を `8001` などに変え、ブラウザでも同じ番号を開きます。
- 画面が真っ白のまま：ブラウザが Chrome か、`http://127.0.0.1:...` で開いているかを確かめます。
- 古い Python で WASM の読み込みに時間がかかる：動作は続きます。Python 3.10 以降をおすすめします。

## 進捗とデータ

- 進捗（達成印や記録）は、このブラウザの中にだけ保存されます。外部へは送りません。
- 別のブラウザや別のポート番号で開くと、進捗は引き継がれません。課題一覧の「進捗を書き出す」で保存したファイルを、移した先で「進捗を読み込む」と移せます。
- 消すとき：課題一覧の「進捗をすべて削除」を使うか、ブラウザの設定で `127.0.0.1` のサイトデータを削除します。
- 演習の途中で画面を閉じると、教材アプリのデータは初期化されます（達成印・適用した対策・ヒントの利用は残ります）。

## 注意

- 教材のサービスとデータはすべて架空です。実在のサービスの診断結果ではありません。
- 演習の合格は、学習の記録です。成績や資格の証明ではなく、本番のサービスを公開してよいことも示しません。
- 学んだ攻撃の手順を、許可のないサービスに試してはいけません。
